# eet2-core

## 0.1.0

### Minor Changes

- První veřejné vydání: sestavení, podpis a odeslání datové zprávy o tržbě do EET 2.0, klasifikace výsledku, načtení pokladního certifikátu (`.p12`, včetně legacy 3DES) a správa certifikátu s automatickou obnovou přes CA EET. Automatická obnova zatím není ověřená proti skutečné CA EET.
